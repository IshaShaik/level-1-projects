Speak commands into your Python backend to navigate effortlessly across this portal.

How It Works

1. Run your local Python script.
2. Say commands like "Open About Page", "Go to AI", or "Contact Page".
3. The browser receives parameters, smoothly scrolls to the section, and speaks confirmation back to you.

About System

This project combines Python speech recognition (`speech_recognition`) with web automation (`webbrowser`) and client-side SpeechSynthesis API to deliver hands-free web navigation.

AI Capabilities

Intelligent routing interprets key phrases from raw spoken language, triggering URL parameters (`?voice=true`) to automate user interfaces smoothly.
