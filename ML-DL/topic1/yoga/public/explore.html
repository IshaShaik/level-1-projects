Take Your Model Further

This app combines MediaPipe pose landmarks with a small machine-learning classifier. The exact TensorFlow.js model can't run directly inside Python, but you can rebuild the same idea there — here's the learning path.

1
Export your training data as JSON.
2
Understand the landmark features — 33 body points, each with x, y, z.
3
Install MediaPipe in Python (pip install mediapipe).
4
Collect pose landmarks from your own webcam using OpenCV + MediaPipe.
5
Train a Python classifier (e.g. scikit-learn or a small Keras model) on the landmark vectors.
6
Test it live through your webcam, the same way this app does.
# pose_starter.py # Educational starting point — mirrors the browser app's approach: # MediaPipe landmarks in, a simple classifier out. import cv2 import mediapipe as mp import numpy as np import json mp_pose = mp.solutions.pose pose = mp_pose.Pose(static_image_mode=False) def normalize(landmarks): pts = np.array([[p.x, p.y, p.z] for p in landmarks]) hip = (pts[23] + pts[24]) / 2 shoulder = (pts[11] + pts[12]) / 2 torso = np.linalg.norm(shoulder[:2] - hip[:2]) or 1.0 return ((pts - hip) / torso).flatten() # 1. Collect samples for each pose class into a list of (label, features) dataset = [] cap = cv2.VideoCapture(0) while True: ok, frame = cap.read() if not ok: break rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB) result = pose.process(rgb) if result.pose_landmarks: features = normalize(result.pose_landmarks.landmark) # Press a key to label + save a sample, e.g.: # dataset.append({"label": "tree_pose", "features": features.tolist()}) cv2.imshow("Pose Capture", frame) if cv2.waitKey(1) & 0xFF == ord('q'): break cap.release() cv2.destroyAllWindows() # 2. Train a simple classifier, e.g. with scikit-learn: # # from sklearn.neural_network import MLPClassifier # X = [d["features"] for d in dataset] # y = [d["label"] for d in dataset] # clf = MLPClassifier(hidden_layer_sizes=(32,), max_iter=500) # clf.fit(X, y) # # Then reuse the same normalize() function at prediction time # on new webcam frames to classify live poses.
